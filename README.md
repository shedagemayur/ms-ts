# ms-ts

A Node.js backend project written in TypeScript.

## Features
- Express.js server structure
- Organized with controllers and routes
- TypeScript configuration for type safety
- Example/mock user data

## Project Structure
```
ms-ts/
├── src/
│   ├── app.ts
│   ├── index.ts
│   ├── users.dump.ts
│   ├── controllers/
│   └── routes/
├── package.json
├── package-lock.json
├── tsconfig.json
└── .gitignore
```

## Getting Started
1. Clone the repository:
   ```sh
   git clone https://github.com/shedagemayur/ms-ts.git
   cd ms-ts
   ```
2. Install dependencies:
   ```sh
   npm install
   ```
3. Build the project:
   ```sh
   npm run build
   ```
4. Start the server:
   ```sh
   npm start
   ```

## Scripts
- `npm run build` – Compile TypeScript to JavaScript
- `npm start` – Start the server
